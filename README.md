### Hey 👋

I'm an associate data scientist at [Solytics Partners](https://github.com/Nuva-Org).

Outside that, I build small tools that kill repetitive work — usually because something annoyed me first. A terminal that wouldn't show me what my agents were doing. An attendance portal I was tired of clicking. A VPN toggle that didn't exist for my bar. They all started as a one-evening fix and grew from there.

Mostly **Python** and **Rust**, on **Arch Linux + Hyprland**.

---

### What I'm building

| | |
| --- | --- |
| **[claude-view](https://github.com/Quantum-vik/claude-view)** <br/> `Rust` `Tauri` | A window per Claude Code session — live terminal mirror, full trace, and what it cost you |
| **[graphify-build](https://github.com/Quantum-vik/graphify-build)** <br/> `Python` | Persistent knowledge graph for codebases. Incremental updates, semantic labeling, multi-repo |
| **[keka-automate](https://github.com/Quantum-vik/keka-automate)** <br/> `Python` `Playwright` | Clocks me in and out of Keka. Captcha OCR, 2FA session reuse, schedules itself |
| **[omarchy-vpn](https://github.com/Quantum-vik/omarchy-vpn)** <br/> `QML` | VPN status and switching in the Omarchy bar, across whichever VPN tool you have installed |
| **[dotfiles](https://github.com/Quantum-vik/dotfiles)** <br/> `Shell` | One machine, reproducible — Omarchy and Ubuntu from the same repo |
